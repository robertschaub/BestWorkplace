# Security

## Scope

This is a public documentation repository with no backend, no API, and no user data.

## Reporting Issues

If you find any of the following, please open a [GitHub issue](https://github.com/robertschaub/BestWorkplace/issues):

- Accidentally committed credentials or API keys
- XSS vulnerabilities in the xWiki viewer
- Malicious content injected into documentation pages
- GitHub Actions workflow issues

## Do Not Commit

- API keys, passwords, or tokens
- `.env` files or personal data
